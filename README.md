# Сайт «Михайловск — Уральская Швейцария»

Статический сайт о городе Михайловске Свердловской области: город и природа,
Вознесенский собор, два музея, туристические маршруты, фотогалерея, контакты.

## Как открыть

Просто откройте `index.html` в браузере (двойной клик) — сайт работает без
установки чего-либо. Интернет нужен только для шрифтов Google Fonts — без
интернета сайт тоже откроется, шрифты подменятся на системные.

Для размещения в интернете достаточно загрузить содержимое этой папки на любой
хостинг (GitHub Pages, Beget, Timeweb и т. д.) — сборка не требуется.

## Структура

```
Сайт/
├── index.html      — главная
├── gorod.html      — город: история, гамаюны, плотина, горы, парки, окрестности
├── sobor.html      — Вознесенский собор: летопись, печи XIX века, колокола, святые
├── muzei.html      — церковно-исторический и краеведческий музеи (цены, мастер-классы)
├── turizm.html     — 4 маршрута из Екатеринбурга, жильё, кафе
├── galereya.html   — фотогалерея (4 альбома, 46 снимков, лайтбокс)
├── kontakty.html   — телефоны и ключевые точки города
├── css/style.css   — все стили
├── js/main.js      — меню, лайтбокс, анимации появления при прокрутке
├── favicon.svg
└── images/
    ├── full/       — полные снимки в WebP (длинная сторона 1920)
    └── thumbs/     — превью в WebP (длинная сторона 720)
```

## Обслуживание

Исходные фотографии лежат в `../готовая инфа/фотографии/`. Скрипты подготовки —
в папке `../_tools/` (Python 3 + Pillow):

- `prepare_images.py` — конвертирует фото в WebP (полные + превью) с ASCII-именами;
- `build_gallery.py` — пересобирает `galereya.html` из списка альбомов с подписями;
- `shoot.py` — делает контрольные скриншоты всех страниц (нужен запущенный
  локальный сервер, см. ниже).

Проверить сайт локально с адресами вида `http://…`:

```
cd Сайт
python -m http.server 8741
```

Затем откройте http://127.0.0.1:8741/

## Правки текста

Все тексты — в самих HTML-файлах, правятся прямо в блокноте. Подписи галереи —
в списке ALBUMS внутри `../_tools/build_gallery.py` (после правки запустите
этот скрипт заново).
